Что такое Git и для чего он используется?



Что такое Git - Git это консольная утилита, для отслеживания и ведения истории изменения файлов, в вашем проекте.



В чём разница между централизованными и распределёнными системами контроля версий?



Главное отличие между централизованными (CVCS) и распределёнными (DVCS) системами контроля версий заключается в том, где хранится полная история проекта и как устроена работа офлайн
