git clone <url> - скопировать удалённый репозиторий на компьютер
git status - показать состояние файлов (изменены, добавлены, не отслеживаются)
git add <файл> - добавить изменения в индекс для следующего коммита
git commit -m "текст" - сохранить добавленные изменения в истории
git push - отправить коммиты в удалённый репозиторий на GitHub
git pull - получить изменения с GitHub и слить их с локальными
git init - создать новый репозиторий в текущей папке
git log - показать историю коммитов
git diff - показать, что именно изменилось в файлах
git branch - показать список веток или создать новую
git checkout <ветка> - переключиться на другую ветку
git remote -v - показать адреса удалённых репозиториев
